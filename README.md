# Cardápio Avalanches

Site do cardápio para clientes (`index.html`) e painel administrativo (`admin.html`).

- `index.html` — cardápio dos clientes
- `admin.html` — painel
- `ativar.html` — ativação do painel
- `sw.js`, `admin.webmanifest` — service worker e manifesto do painel
- `_worker.js` — Worker do Cloudflare Pages (gerado a partir de `site-worker.js`)
